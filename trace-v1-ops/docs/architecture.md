# 睿码溯源系统 - 架构说明

## 一、系统概述

睿码溯源系统（RuiTrace Platform）是一款基于微服务架构的企业级防伪溯源解决方案，采用前后端分离架构，通过容器化部署实现快速交付和弹性扩展。

## 四、核心模块

### 4.1 批次管理模块

**功能说明**：
- 创建、查询、修改批次信息
- 批次状态跟踪（pending/processing/done）
- 批次与二维码关联管理

**数据模型**：
```python
class Batch(Base):
    id: int
    batch_no: str          # 批次号（唯一）
    product_name: str      # 产品名称
    total_count: int       # 总数量
    status: str            # 状态
    created_at: datetime   # 创建时间
```

### 4.2 二维码管理模块

**功能说明**：
- 批量生成唯一二维码
- 二维码签名与验证
- 二维码图片存储与管理
- 导出Excel/ZIP格式

**数据模型**：
```python
class TraceCode(Base):
    id: int
    code_id: str           # 二维码ID（唯一）
    batch_no: str          # 所属批次
    product_name: str       # 产品名称
    qr_path: str           # 二维码路径
    signature: str         # 签名
    created_at: datetime   # 创建时间
```

### 4.3 扫码溯源模块

**功能说明**：
- 扫码记录存储
- IP地理位置分析
- 风险检测与预警
- 传播链分析

**数据模型**：
```python
class ScanLog(Base):
    id: int
    code_id: str           # 被扫二维码
    ip: str                # 扫码IP
    city: str              # 城市
    province: str          # 省份
    scan_time: datetime    # 扫码时间
    verify_result: str     # 验证结果
    risk_level: str        # 风险等级
```

### 4.4 任务管理模块

**功能说明**：
- 异步任务创建与调度
- 任务进度实时跟踪
- 任务结果存储与下载
- 失败任务重试

**数据模型**：
```python
class BatchTask(Base):
    id: int
    batch_no: str          # 关联批次
    task_type: str         # 任务类型（generate/export）
    status: str            # 状态
    progress: int         # 进度 0-100
    total: int            # 总数
    success: int          # 成功数
    failed: int           # 失败数
    result_path: str      # 结果文件路径
```

## 五、数据流

### 5.1 二维码生成流程

```
用户请求
    ↓
创建批次（API: POST /api/batch/create）
    ↓
创建任务（API: POST /api/code/batch_generate）
    ↓
Worker接收任务
    ↓
ThreadPoolExecutor 并行生成二维码
    ↓
写入数据库（TraceCode表）
    ↓
保存图片文件（static/qrcode/）
    ↓
更新任务进度
    ↓
任务完成
```

### 5.2 扫码溯源流程

```
用户扫码
    ↓
访问验证API（GET /api/verify/{code_id}）
    ↓
查询二维码信息
    ↓
记录扫码日志（ScanLog表）
    ↓
IP地理位置分析
    ↓
风险检测
    ↓
返回验证结果
```

## 七、安全机制

### 7.1 身份认证

- JWT Token 认证
- Token 过期时间：30分钟
- 密码加密存储（pbkdf2_sha256）

### 7.2 签名验证

- 二维码签名：基于 HMAC-SHA256
- 签名密钥：每个二维码唯一
- 防伪造机制

### 7.3 风险控制

- 高频扫码检测
- 异地扫码检测
- IP黑名单
- 风险评分系统
